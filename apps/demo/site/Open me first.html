Sunmarke Lab Booking demo

The full booking site, running on your own computer. Nothing to install, and nothing is sent anywhere.

1. Start it

  1. Unzip the whole folder first (right-click the zip, then Extract All). It will not run from inside the zip.
  2. Windows: double-click Start demo (Windows).bat. If Windows shows "Windows protected your PC", choose More info, then Run anyway.
  3. Mac: right-click Start demo (Mac).command, choose Open, then Open again.
  4. A small window opens and your browser opens the site after a few seconds. Keep that window open while you use the demo. Closing it stops the demo.

2. Open the site

Open the demo site

If the button shows an error, start the demo first (step 1).

3. Sign in

On the sign-in page, press Try a demo account and pick anyone. Some to try:

AccountWhat you see
A teacher (Sara Khan)Book a lab or AI Carts from the week grid, My bookings, the booking assistant
Ram, Abdul or NaelThe lab in-charge calendar, today's sessions, leave and blocked time
AbdAdmin: labs, staff, timetables, rules, and booking for any teacher
Dr. Sreejit or Dr. NeilReports by lab, teacher and in-charge, with CSV downloads

Sign-in here is a stand-in. The real site will use school Google or Microsoft sign-in.

Good to know

  1. Bookings you make are kept in the data folder, so they are still there next time. To start over, close the demo and double-click Reset demo data.
  2. Teams messages are not sent. You can read them on the site's Messages page.
  3. The site only answers on this computer, so other people on the network cannot reach it.
